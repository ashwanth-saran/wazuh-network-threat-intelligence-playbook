# 🛡️ Wazuh Network Threat Intelligence Playbook

Welcome! 👋

This project demonstrates how to automate security alerts generated by **Wazuh** using **n8n** and enrich them with real-time threat intelligence before sending them to **Telegram**.

Instead of manually investigating every suspicious IP address, this workflow automatically gathers reputation information from multiple threat intelligence sources and delivers everything in a single alert.

This project is ideal for anyone learning:
- Wazuh
- n8n Automation
- SOC Analyst workflows
- Threat Intelligence
- Security Automation (SOAR)

---

# 📖 What is this project?

Imagine your Wazuh server detects someone trying to log in to your Linux server using an invalid username.

Normally, you would need to:

- Copy the IP address
- Search VirusTotal
- Search AbuseIPDB
- Check where the IP is located
- Decide whether it is malicious

This project automates all of those steps.

Within a few seconds, Telegram receives a fully enriched security alert.
